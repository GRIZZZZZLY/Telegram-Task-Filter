# Этап 3 — React UI (apps/desktop/)

**Дата:** 2026-02-25  
**Статус:** В работе

## Цель

Поднять полноценный React-фронтенд в `apps/desktop/` — от пустого scaffold'а до рабочего UI с задачами, WebSocket-обновлениями и Setup Wizard. Tauri-обёртку не трогаем (Rust не установлен) — запускаем через `vite dev`.

## Стек

- React 18 + TypeScript + Vite
- Tailwind CSS + shadcn/ui
- framer-motion
- Magic UI (copy-paste через CLI): BentoGrid, Interactive Hover Button, Animated Theme Toggler
- Eldora UI (copy-paste): Clerk OTP Input
- Fancy Components (copy-paste): Animated Gradient SVG Background

**Файлы:**

**Логика:**
- Done → POST /tasks/{id}/done → карточка в Done таб
- WS task_created → новая карточка анимированно в Inbox
- WS task_committed → убрать undo-toast
