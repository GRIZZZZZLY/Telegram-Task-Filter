Place your custom Windows icon here as `icon.ico`.

Recommended sizes packed inside the ICO file:
- 16x16
- 32x32
- 48x48
- 64x64
- 128x128
- 256x256

Used by:
- tray icon (runtime, fallback to generated square if missing)
- notification icon (runtime)
- electron-builder packaging (set `build.win.icon` when ready)
