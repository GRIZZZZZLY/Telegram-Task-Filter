## Статистика

Шапка: кнопка «назад», значок графика, заголовок «Статистика», кнопка обновления с подсказкой «Обновить».

Периоды: «Сегодня», «Неделя», «Всё время», «Период...». По умолчанию неделя. Смена периода сразу перезагружает данные, кроме «Период...».

Для «Период...»: два поля даты, тире между ними, кнопка «Показать». Кнопка недоступна, пока обе даты не заданы.

Состояния: ошибка с текстом «Ошибка загрузки статистики», самой ошибкой и кнопкой «Повторить»; индикатор при первой загрузке; данные.

Карточки сводки, четыре штуки:

| Подпись | Значение | Примечание |
|---|---|---|
| Всего задач | число | нет |
| Выполнено | число | зелёным |
| В работе | число | акцентным |
| Среднее время | «N мин», «N ч», «N ч M мин» или «—» | «от создания до выполнения» |

Разделы графиков: «По дням», «По приоритету», «По чатам», «По веткам», «По отправителям». Пустой раздел показывает «Нет данных».

График по дням: не более последних 14 дней, столбик «создано» и поверх него более узкий «выполнено», подписи первой, средней и последней даты, легенда «Создано» и «Выполнено».

Горизонтальные полосы: подпись слева обрезается, полоса, число справа. Минимальная видимая длина полосы два процента. Приоритеты идут в порядке HIGH, MED, NORM, LOW со своими цветами. Ветка подписана как «чат › #id». Отправитель подписан именем или «id:N». Имя чата берётся из карты имён, иначе «чат …1234».

## Вход в Telegram

Три шага с указателем 1-2-3. Заголовок «Подключение Telegram» и подпись, меняющаяся по шагу:

- «Войдите в аккаунт, чтобы получать задачи из чатов»
- «Код отправлен в Telegram на <номер>»
- «Требуется пароль двухфакторной аутентификации»
- «Telegram успешно подключён»

Шаг 1. Если ключи не настроены: блок «API-ключи Telegram», ссылка «Получить на my.telegram.org → Apps», поля «API ID» и «API Hash». Если настроены: «✓ API-ключи уже настроены в .env — вводить повторно не нужно». Поле «Номер телефона», Enter отправляет. Кнопка «Отправить код».

Ошибки шага 1: «Введите API ID и API Hash от my.telegram.org», «Введите номер телефона», текст ошибки сервера.

Шаг 2. Поле «Код из Telegram», Enter подтверждает. Подсказка «💡 Если на аккаунте установлён пароль двухфакторной аутентификации (2FA), он потребуется после ввода кода.»

Если сервер ответил кодом 422, появляется блок двухфакторной проверки: «Аккаунт защищён двухфакторной аутентификацией. Введите пароль 2FA, который вы установили в настройках Telegram.» и поле «Пароль 2FA». Поле кода становится только для чтения и приглушается.

Кнопка «Подтвердить», в режиме двухфакторной проверки «Войти». Ссылка «← Изменить номер» возвращает на первый шаг и очищает код, пароль и признак 2FA.

Ошибки шага 2: «Введите код из Telegram», «Введите пароль 2FA», «Неожиданный ответ сервера», текст ошибки сервера.

Шаг 3: галочка, «Подключено», имя подключённого аккаунта, «Приложение загружается...».

## Мастер первичной настройки

Делает ровно то же самое: ключи, телефон, код, пароль. Отличия: всегда требует ключи, показывает код пятью отдельными ячейками, помечает завершение в памяти браузера ключом `tgff_setup_complete`.

Мастер удаляется. Поле из пяти ячеек переезжает в экран входа. Флаг завершения больше не нужен: оболочка и так спрашивает сервер о состоянии подключения и сама показывает экран входа.

Поле из пяти ячеек: ввод цифры переводит фокус вперёд, Backspace на пустой ячейке возвращает назад и стирает предыдущую, стрелки двигают фокус, вставка из буфера раскладывает цифры по ячейкам, фокус выделяет содержимое.

## Экран PIN

Четыре точки, цифровая клавиатура 1-9, 0 и стирание. Ввод с физической клавиатуры тоже работает. Автоматическая отправка, когда набраны все четыре цифры.

Заголовки: «Введите PIN-код», в режиме установки «Установите PIN-код» и «Повторите PIN-код». Подписи: «Для доступа к приложению», «PIN защитит доступ к приложению и Telegram-сессии», «Введите тот же PIN ещё раз для подтверждения».

Ошибки: «Неверный PIN», «Ошибка соединения», «PIN не совпадает. Попробуйте снова», «Ошибка установки PIN», «Слишком много попыток. Подождите Nс», «Заблокировано на Nс» с обратным отсчётом.

При ошибке экран встряхивается. Во время блокировки клавиатура не отвечает.

В режиме установки внизу ссылка «Пропустить (не рекомендуется)».

## Окно обновления

Появляется само, когда сервер сообщил о новой версии. Заголовок «Доступно обновление», под ним «vТекущая → vНовая». Крестик закрытия только в состоянии «доступно».

Описание изменений тянется с GitHub по тегу версии. Пока грузится: «Загрузка описания...». Если не получено: «Описание изменений недоступно.» Разметка описания: строки, начинающиеся с двух решёток, показываются жирным; строки с дефисом или точкой в начале как пункты списка.

Состояния и кнопки:

| Состояние | Что видно |
|---|---|
| доступно | «Пропустить» и «Обновить», клик по затемнению закрывает |
| загрузка | полоса с процентами, «Загрузка... N%», кнопка заблокирована |
| загружено | «Обновление загружено и готово к установке», кнопки «Позже» и «Установить и перезапустить» |
| ошибка | текст ошибки или «Ошибка при загрузке обновления», кнопки «Закрыть» и «Повторить» |
