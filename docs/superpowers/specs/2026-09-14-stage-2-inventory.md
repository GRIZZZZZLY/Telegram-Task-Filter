Это контракт. После переписывания каждый пункт проверяется вручную. Ничего из
перечисленного не должно исчезнуть без отдельного решения.

## Контракт хука `useTasks` — не меняется

Список получает от хука: `tasks`, `loading`, `error`, `actionError`, `loadingId`,
`pendingUndo` (`{id, title} | null`), `pendingDismiss` (`{id, title} | null`),
`failedCommitIds` (`Set<number>`).

Действия: `handleDone(id, customReply?)`, `handleDismiss(id)`, `handleSnooze(id, minutes)`,
`handleReopen(id)`, `handleUndoDone(id)`, `handleUndoDismiss()`, `clearActionError()`,
`handlePriorityChange(id, priority)`, `handleReorder(ids)`, `handlePin(id)`,
`handleStartWork(id)`, `clearUndo()`, `refetch()`, `setTasks(...)`.

## Список задач

### Состояния экрана

| Состояние | Что показано |
|---|---|
| Загрузка | Крутящийся индикатор по центру |
| Ошибка загрузки | Текст ошибки и строка «Убедитесь, что бэкенд запущен на порту 8787» |
| Пусто, вкладка Inbox | «Нет активных» |
| Пусто, вкладка Done | «Нет завершённых» |
| Пусто, вкладка Snoozed | «Нет отложенных» |
| Поиск без совпадений | «Ничего не найдено» |

### Плашки над списком

Ошибка действия: «Не получилось: <текст>», роль `alert`, крестик с подписью
«Скрыть сообщение», сама гаснет через 5 секунд. Список под ней остаётся.

Отмена удаления: «Убрано: <заголовок>», роль `status`, кнопка «Отменить».

### Поиск

Поле с подсказкой «Поиск по задачам... (Ctrl+F)». Фильтрует по заголовку и телу,
без учёта регистра. Escape в поле очищает текст и снимает фокус. Крестик справа
появляется при непустом поле и очищает его.

### Очистка выполненных

На вкладке Done, когда список не пуст: кнопка «Очистить все». Спрашивает
подтверждение «Удалить все выполненные задачи?» через системное окно. Пока идёт
удаление, кнопка заблокирована и крутится индикатор.

### Перетаскивание

Только на вкладке Inbox и только для незакреплённых задач. Закреплённую нельзя
ни взять, ни бросить на неё. Порядок меняется локально, затем уходит на сервер
целиком списком. Подсветка цели перетаскивания и приглушение взятой строки.

### Клавиатура

Вкладка Inbox и никакая панель не открыта: Ctrl+D завершает выбранную задачу,
Ctrl+Z отменяет, Ctrl+F ставит курсор в поиск, стрелки двигают выбор, Escape
закрывает панель или очищает поиск. Выбранная задача обведена рамкой.

### Прочее

Клик по строке помечает её выбранной. Счётчик Inbox сообщается наверх при каждом
изменении длины списка. Режимы показа: `compact`, `standard`, `expanded`.

## Карточка задачи

### Действия, все пятнадцать

| Действие | Где сейчас | Условие |
|---|---|---|
| Сменить приоритет | Плашка NORM/HIGH/MED/LOW, клик по кругу | Только inbox |
| Открыть подробности | Кнопка со стрелками в углу | Всегда |
| Открыть в Telegram | Кнопка со стрелкой в углу | Всегда |
| Удалить | Корзина в углу | Только inbox |
| Развернуть и свернуть текст | «Развернуть» / «Свернуть» под текстом | Есть тело, режим не compact и не expanded |
| Выполнено | Кнопка «Done» | Не done и не snoozed |
| Выполнено со своим ответом | Стрелка рядом с «Done», открывает поле | Не done и не snoozed |
| Отправить свой ответ | Enter в поле или галочка | Поле открыто |
| Закрыть поле ответа | Escape в поле | Поле открыто |
| В работу и снять | Кнопка «В работу» / «В работе» | Только inbox |
| Отложить | Часы, открывают меню на три пункта | Только inbox |
| Закрепить и открепить | Булавка | Только inbox |
| Вернуть в inbox | «Вернуть» на done, «В inbox» на snoozed | done или snoozed |
| Отменить выполнение | «Отменить» в полосе обратного отсчёта | Окно отмены открыто |
| Перетащить | Ручка с точками | Inbox, не закреплена |
| Открыть профиль автора | Клик по имени отправителя | Есть username |
| Открыть ссылку в тексте | Клик по ссылке | В тексте есть ссылка |

### Сроки откладывания

«1 час», «3 часа», «Завтра утром» (до 9 утра следующего дня). Меню открывается
вверх или вниз в зависимости от места на экране, рисуется через портал, закрывается
кликом мимо.

### Метки состояния

Закреплено, «⚠ источник изменён» с подсказкой про редактирование в Telegram,
«⚠ Реакция не отправлена» с подсказкой про логи, вложение с иконкой и словом
(Фото, Видео, Голосовое, Аудио, Геолокация, Вложение), реакции коллег
сгруппированы по эмодзи с именами в подсказке.

### Окно отмены

После нажатия «Done» карточка превращается в полосу: «✅ <заголовок> выполнено»,
заголовок обрезается на 40 знаках, кнопка «Отменить», и тонкая полоска внизу
утекает за 5 секунд. По истечении вызывается `onDoneExpire`.

### Время

Сегодня — часы и минуты, меньше минуты назад — «только что», вчера — «вчера ЧЧ:ММ»,
раньше — «5 сент 14:30». Для отложенной задачи вместо времени: «⏰ 40 мин», «⏰ 3 ч»
или дата. Всё в часовом поясе устройства.

### Имена и ссылки

Заголовок и тело чистятся от упоминаний перед показом. Ссылки в тексте
кликабельны, знаки препинания в конце не съедаются. Имя чата берётся из карты
имён, иначе «чат …1234». Тема берётся из карты, иначе «тема #12».

Ссылка на сообщение: для каналов `tg://privatepost?channel=...&post=...`, для
остальных `tg://resolve?domain=...&post=...`. В браузере открывается веб-версия.

## Окно задачи

Открывается кнопкой на карточке. Закрывается крестиком, кликом по затемнению и
Escape. Показывает: полосу приоритета, плашку приоритета с возможностью сменить
на inbox, заголовок, отправителя со ссылкой на профиль, чат, тему, полную дату
словами, предупреждение об отредактированном источнике, реакции коллег с подписью
«Реакции коллег:», полный текст с прокруткой, вложение с кнопкой «Открыть в Telegram».

Внизу: «Done» или «Вернуть в inbox» или «В inbox», «Отложить» с тем же меню на три
пункта, «Убрать» на inbox, «В Telegram» справа. Любое действие закрывает окно.
