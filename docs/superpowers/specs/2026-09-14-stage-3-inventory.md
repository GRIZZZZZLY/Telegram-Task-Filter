# Опись поведения: настройки и выбор чатов

Снято 14 сентября 2026 с файлов `SettingsScreen.tsx` (1383 строки) и
`ThreadSelector.tsx` (578 строк) перед переписыванием на этапе 3.

Это контракт. После переписывания каждая строка проверяется вручную. Ни одна
настройка не исчезает и не меняет смысл.

## Экран настроек: каркас

Шапка: кнопка «назад», заголовок «Настройки», справа две кнопки.

| Кнопка | Что делает | Состояния |
|---|---|---|
| Сохранить | Сохраняет настройки | «Сохранить» → крутящийся индикатор → «✓ Ok» на 1,5 секунды |
| Применить | Сохраняет и перезапускает слушатель чатов | Подсказка «Сохранить настройки и перезапустить слушатель чатов», индикатор на время работы, флаг «✓ Ok» на 2 секунды |

Обе кнопки заблокированы, пока идёт сохранение или настройки не загружены.

Состояния экрана: ошибка загрузки с текстом ошибки и кнопкой «Повторить»;
загрузка с индикатором; загружено. Внизу подпись «TG Focus Filter vX.Y.Z».

## Раздел 1. Telegram

- Поле «Мой Telegram handle» с пояснением «Задачи создаются только для сообщений, где упомянут ваш @тег». Ввод тегами: Enter или запятая добавляет, собака подставляется автоматически, повтор не добавляется, крестик удаляет.
- «Отслеживаемые чаты и ветки» — выбор чатов, описан ниже.
- Подсказка «⚡ После изменения чатов нажмите **Применить** — это перезапустит слушатель.»

## Раздел 2. Фильтры

| Настройка | Управление | Пояснение |
|---|---|---|
| Игнорировать свои сообщения | переключатель | нет |
| Минимальная длина текста | число 0–2000 | «Сейчас: N симв.» |
| Контекст из reply | переключатель | «Если сообщение короткий пинг с @тегом, брать суть задачи из родительского сообщения» |
| Порядок задач в inbox | две кнопки «Новые сверху» и «Новые снизу» | нет |
| Высокий приоритет выше | переключатель | «Сначала HIGH, потом MED, LOW, NORM» |

## Раздел 3. Реакция на выполнение

- «Отправлять реакцию», пояснение «Ставить эмодзи-реакцию на сообщение при выполнении».
- Если включено: выбор из восьми эмодзи 👍 ❤ 🔥 🎉 👏 🤝 💯 ✍ под подписью «Реакция».
- «Отправлять ответ в чат»; если включено, поле «Текст ответа».
- «Задержка реакции», ползунок 0–60, пояснение «N сек — время на отмену».
- «Реакция на кастомный ответ», пояснение «Ставить отдельную реакцию, когда задача выполнена с кастомным текстом».
- Если включено: подпись «Реакция для кастомного ответа» с примечанием «(пусто = как основная)», кнопка «как основная» плюс те же восемь эмодзи.

## Раздел 4. Очистка

| Настройка | Управление | Пояснение |
|---|---|---|
| Авто-удаление выполненных | число 0–365 | «Выключено» при нуле, иначе «Через N дн.» |
| Удалить все выполненные сейчас | кнопка «Очистить» | Подтверждение «Удалить все выполненные задачи?», затем сообщение «Удалено N задач» |
| Аварийная очистка inbox | кнопка «Очистить inbox» | Пояснение «Удалит только локальные inbox-задачи». Подтверждение «Очистить ВСЕ задачи во вкладке Inbox?\n\nЭто удалит только локальные задачи в приложении (без действий в Telegram).», затем «Удалено N задач из inbox» |

Ошибки очистки показываются как «Ошибка очистки» и «Ошибка очистки inbox».

## Раздел 5. Сканирование истории

- «Авто-скан при запуске», пояснение «Сканировать историю сообщений при каждом запуске приложения».
- Если включено: «Глубина скана», число 1–168, пояснение «Последние N ч».
- «Ручной скан истории»: «За последние» + число 1–168 + «ч» + кнопка «Сканировать».
- Результат скана: «Просмотрено: N · Создано: N · Уже выполнено: N · Дубли: N», либо «Ошибка сканирования», либо «Ошибка: текст».
- Блок «Проверка guard» с кнопкой «Guard» и описанием «Что делает: проверяет, что реакции/ответы стоят только на сообщениях с твоим тегом; неверные реакции снимает и удаляет наш reply.»
- Результат guard: «Проверено: N · Ок: N · Откат: N · Пропущено: N» либо «Ошибка guard: текст».

## Раздел 6. Безопасность

Если PIN установлен: строка «PIN-код» с пояснением «Защита доступа к приложению и Telegram-сессии» и меткой «Установлен». Блок «Сменить PIN» с тремя полями: «Текущий PIN», «Новый PIN (4-6 цифр)», «Повторите новый PIN». Кнопка «Сменить PIN», во время работы «Сохранение...». Ошибки: «Новый PIN не совпадает с подтверждением», «Неверный текущий PIN». Успех: «PIN изменён».

Если PIN не установлен: метка «Не установлен», блок «Установить PIN» с двумя полями «PIN (4-6 цифр)» и «Повторите PIN». Кнопка «Установить PIN». Ошибки: «PIN не совпадает с подтверждением», «Ошибка установки PIN». Успех: «PIN установлен! При следующем запуске потребуется ввод PIN».

Все поля принимают только цифры, максимум шесть. Кнопка заблокирована, пока новый PIN короче четырёх цифр.

Строка «Автоблокировка» с пояснением «Через сколько минут без действий запрашивать PIN (0 = выкл)», ползунок 0–30, подпись «Выкл» или «N мин». Значение хранится на стороне приложения, а не на сервере.

## Раздел 7. Внешний вид

| Настройка | Управление | Пояснение |
|---|---|---|
| Системные уведомления | переключатель, дублируется в Electron | «Всплывающие тосты Windows» |
| Звук уведомлений | переключатель, дублируется в звуковой модуль | «Только если уведомления включены» |
| Пресет звука | выпадающий список пресетов, кнопка ▶ для проверки | видно, только когда звук включён |
| Путь к файлу | поле, кнопка ▶ | видно, только когда выбран пресет «custom»; пояснение «MP3 или OGG, например: /sounds/my.mp3» |
| Режим отображения задач | три кнопки «Компактный», «Стандартный», «Развёрнутый» | «Компактный / Стандартный / Развёрнутый» |

## Раздел 8. Обновления приложения

Вне Electron: «Обновления доступны только в desktop-сборке Electron.»

В Electron: строка «Текущая версия» со значением и пояснением «Доступна версия X» при наличии. Сообщение о состоянии. Полоса загрузки с процентами при скачивании. Кнопки «Проверить обновления», «Скачать» (во время работы «Загрузка…»), «Перезапустить и установить». Примечание «Автообновление поддерживается для установленной версии (NSIS). Portable обновляется вручную.»

## Раздел 9. Диагностика

- Переключатель режима: «Понятный» и «Технический».
- В техническом режиме: выбор уровня («Все уровни», «Только ошибки», «Предупреждения», «INFO») и количества строк (50, 100, 200, 500).
- Кнопка «Загрузить», после первой загрузки «Обновить».
- Кнопка «Папка логов» только в Electron, подсказка «Открыть папку с логами в Проводнике».
- Ошибка: «Ошибка: текст».
- Понятный режим: список событий с иконкой, текстом и временем; ошибки и предупреждения выделены. Пусто: «Нет событий для отображения. Попробуй «Технический» режим для деталей.»
- Технический режим: имя файла, число строк, текст лога моноширинным шрифтом; строки с ERROR и WARNING выделены. Пусто: «Лог пуст или нет строк выбранного уровня.»

## Выбор чатов и веток

Две раскрывающиеся секции, обе открыты по умолчанию.

### Секция «Группы»

Подпись справа: «все чаты», когда ничего не выбрано, иначе «N выбрано».
Поле «Поиск групп...» фильтрует по названию и по идентификатору. Кнопка обновления списка с подсказкой «Обновить список групп».

Состояния: индикатор при первой загрузке; «Telegram не подключён или групп нет»; «Ничего не найдено»; список с галочками.

Снятие галочки с группы удаляет и все её выбранные ветки.

### Секция «Ветки»

Подпись справа: «все ветки», когда ничего не выбрано, иначе «N выбрано».
Пока группы не выбраны: «Сначала выберите группы выше».

Вкладки по выбранным группам, по три на страницу, со стрелками влево и вправо и указателем «1/3». На вкладке значок «✓N» с числом выбранных веток. Кнопка перезагрузки веток с подсказкой «Перезагрузить ветки».

Поле «Поиск веток...» фильтрует по названию и идентификатору. Две кнопки: «Все» (подсказка «Выбрать все ветки», при поиске «Выбрать найденные») и «Сброс» (подсказка «Сбросить выбор веток»). «Все» выбирает только найденные, «Сброс» снимает весь выбор для вкладки независимо от поиска.

Состояния: индикатор загрузки; «Нет тем — группа не является форумом или тем недоступны. Оставьте пустым — слушать все ветки.»; «Ничего не найдено»; список веток с галочкой, названием и номером «#id».

При смене вкладки поиск по веткам очищается. Ветки грузятся по требованию и кэшируются.

### Формат хранения

Чаты: список идентификаторов через запятую. Ветки: пары «идентификатор чата:идентификатор ветки» через запятую. При разборе токен обрезается по последнему двоеточию, кавычки по краям снимаются, пустые и неправильные токены пропускаются. Это единственная нетривиальная чистая логика на экране, и она переезжает в отдельный файл с тестами.
