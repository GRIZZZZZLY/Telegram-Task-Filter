# Шпаргалка по авторизации в Telegram

---

## Что нужно перед началом

1. **Telegram API credentials** — получить на [my.telegram.org/apps](https://my.telegram.org/apps):
   - `API ID` — число (например: `1234567`)
   - `API Hash` — строка из 32 символов (например: `abc123def456...`)
2. **Номер телефона** — тот, к которому привязан Telegram-аккаунт (формат: `+79001234567`)
3. **Доступ к Telegram** — нужно получить код подтверждения в приложении

---

## Как получить API ID и API Hash

1. Открыть [my.telegram.org/apps](https://my.telegram.org/apps) в браузере
2. Войти с номером телефона (придёт код в Telegram)
3. Нажать **«Create application»** (если приложения нет)
4. Заполнить любое название (например: `My Filter`)
5. Скопировать **App api_id** и **App api_hash**

> Ссылка `my.telegram.org/apps` доступна прямо из интерфейса приложения на шаге ввода credentials.

## Флоу авторизации в приложении

### Шаг 1 — Credentials

```
┌─────────────────────────────────────┐
│  API ID      [_____________]        │
│  API Hash    [_____________]        │
│  Телефон     [+79001234567]         │
│                                     │
│         [Отправить код]             │
└─────────────────────────────────────┘
```

- Ввести API ID, API Hash и номер телефона
- Нажать **«Отправить код»**
- Telegram отправит код в приложение (чат с номером **777000**)

> Если API-ключи уже были введены ранее — поля будут скрыты, показывается баннер «API-ключи уже настроены».

---

### Шаг 2 — Код подтверждения

```
┌─────────────────────────────────────┐
│  Код из Telegram                    │
│         [  1 2 3 4 5  ]             │
│                                     │
│  💡 Если установлен пароль 2FA,     │
│     он потребуется на следующем     │
│     шаге после ввода кода.          │
│                                     │
│  [← Изменить номер]  [Подтвердить] │
└─────────────────────────────────────┘
```

- Открыть Telegram → найти сообщение от **Telegram** (чат 777000)
- Ввести 5-значный код
- Нажать **«Подтвердить»**

---

### Шаг 2b — Двухфакторная аутентификация (2FA)

Если на аккаунте установлен облачный пароль, после ввода кода появится:

```
┌─────────────────────────────────────┐
│  Код из Telegram                    │
│         [  1 2 3 4 5  ]  (readonly) │
│                                     │
│  🔒 Требуется пароль 2FA            │
│     Введите облачный пароль         │
│     Telegram-аккаунта               │
│                                     │
│  Пароль 2FA  [______________]       │
│                                     │
│  [← Изменить номер]      [Войти]   │
└─────────────────────────────────────┘
```

- Ввести облачный пароль (тот, что установлен в Telegram → Настройки → Конфиденциальность → Двухэтапная аутентификация)
- Нажать **«Войти»**

---

### Шаг 3 — Успех

```
┌─────────────────────────────────────┐
│           ✅ Подключено             │
│           @username                 │
└─────────────────────────────────────┘
```

Приложение переходит в основной режим. Авторизация завершена.

## Где хранится сессия

| Режим | Путь |
|---|---|
| Packaged `.exe` | `%APPDATA%\tg-focus-filter-desktop\sessions\user.session` |
| Dev | `D:\Telegram-Task-Filter\sessions\user.session` |

Файл `user.session` — это SQLite-база Telethon. Он создаётся автоматически при успешной авторизации.

> **Не удалять** этот файл без необходимости — при удалении потребуется повторная авторизация.

---

## Перенос сессии с dev на packaged

Если авторизация была пройдена в dev-режиме, сессия автоматически копируется при первом запуске `.exe`:

```
D:\Telegram-Task-Filter\sessions\user.session
    → %APPDATA%\tg-focus-filter-desktop\sessions\user.session
```

Если автомиграция не сработала — скопировать файл вручную.

---

## Экран «Telegram не подключился»

Появляется когда сессия существует, но подключение не удалось (нет интернета, rate-limit и т.д.):

```
┌─────────────────────────────────────┐
│  ⚡ Telegram не подключился         │
│                                     │
│  Сессия найдена, но сервис          │
│  не смог подключиться.              │
│                                     │
│  [Повторить]    [Войти заново]      │
└─────────────────────────────────────┘
```

- **«Повторить»** — попробовать подключиться снова (не удаляет сессию)
- **«Войти заново»** — сбросить и пройти авторизацию заново

## Ручная авторизация через CLI (dev)

Если нужно авторизоваться без запуска Electron:

```powershell
cd D:\Telegram-Task-Filter
# Убедиться что .env заполнен (TG_API_ID, TG_API_HASH, TG_PHONE)
.venv\Scripts\python.exe scripts\auth_telegram.py
```

Скрипт создаст `sessions\user.session` в корне проекта.

---

## Ручное заполнение `.env`

Если нужно настроить credentials без UI — отредактировать файл `.env`:

**Dev:** `D:\Telegram-Task-Filter\.env`  
**Packaged:** `%APPDATA%\tg-focus-filter-desktop\.env`

```env
TG_API_ID=1234567
TG_API_HASH=abc123def456abc123def456abc123de
TG_PHONE=+79001234567
```

После редактирования — перезапустить приложение.

## Частые проблемы

| Проблема | Решение |
|---|---|
| «Неверный код» | Код действует ~5 минут. Запросить новый через «← Изменить номер» → «Отправить код» |
| «Слишком много попыток» (FloodWait) | Подождать указанное время (обычно несколько минут) |
| 2FA пароль не принимается | Убедиться что вводится облачный пароль Telegram, а не PIN телефона |
| Сессия протухла | Удалить `user.session`, перезапустить приложение, авторизоваться заново |
| Код не приходит | Проверить чат **777000** в Telegram. Если нет — попробовать через SMS (кнопка в Telegram) |
| `API ID invalid` | Проверить что API ID — число, не строка. Пересоздать приложение на my.telegram.org |
